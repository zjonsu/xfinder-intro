왜 만들었나

파인더는 좋지만, 늘 아쉬웠던 것들

매일 쓰는 파일 관리자라면 키보드만으로 막힘없이 움직이고, 어수선한 폴더는 한마디로 정리되고, 안 쓰는 앱은 찌꺼기까지 깔끔하게 지워지면 좋겠다고 생각했습니다.

XFinder는 Finder의 익숙한 레이아웃을 그대로 가져오되, 그 위에 평소 직접 손이 가던 작업들 — AI 정리, 시스템 모니터링, 앱 삭제, 한글·윈도우 파일명 정리 — 을 하나의 네이티브 앱으로 묶은 개인 프로젝트입니다.

필요한 건 다 들어있습니다

기본 탐색·파일 작업부터, 파인더에 없는 똑똑한 기능까지.

파인더 스타일 탐색

즐겨찾기·위치·태그 사이드바와 디스클로저 트리, 클릭 가능한 경로 막대, 뒤로/앞으로/상위 히스토리. 익숙한 그대로입니다.

완전한 파일 작업

새 폴더·이름 변경·복제·휴지통 이동, 그리고 복사 / 잘라내기 / 붙여넣기 클립보드. 파인더·다른 앱과도 클립보드를 주고받습니다.

AI 파일 정리★ 특별

“hwp 파일 휴지통으로, 이미지는 그림 폴더로” 한국어 한 줄이면 AI가 정리 계획을 세워 보여줍니다. 로컬 Ollama 또는 Gemini.

시스템 모니터★ 특별

툴바에 CPU·메모리·디스크 사용률이 실시간으로. 클릭하면 추이 그래프, CPU 온도, 메모리 분류, 디스크 용량·S.M.A.R.T. 상태까지.

앱 완전 삭제★ 특별

AppCleaner처럼 — 앱을 지울 때 캐시·환경설정·컨테이너 등 흩어진 관련 파일까지 찾아 한 번에 휴지통으로. 보호된 항목은 Finder에 위임.

한글 파일명 복원★ 특별

자소가 분리돼 “ㅎㅏㄴ”처럼 깨진 한글 이름(NFD)을 정상(NFC)으로 복원. 이 폴더만, 또는 하위 폴더까지 한 번에.

윈도우 호환 파일명

파일을 만들거나 이름을 바꿀 때 \ / : * ? " < > | 같은 금지 문자와 예약 이름을 자동 정리해 윈도우에서도 깨지지 않게.

파인더 태그

macOS 표준 7색 태그를 그대로 읽고 씁니다. 사이드바에서 색을 누르면 그 태그가 붙은 파일만 스포트라이트로 모아 보여줍니다.

최근 항목 & 빠른 검색

스포트라이트 기반 ‘최근 항목’(종류별 필터 지원), 그리고 현재 폴더의 모든 하위 폴더를 훑는 즉시 검색.

압축 & 미리 보기

ZIP 압축·압축 풀기를 진행 표시와 함께. Space / F3로 macOS 기본 Quick Look 미리 보기.

키보드 우선

전역 키 모니터로 목록을 클릭하지 않아도 25개 이상의 단축키가 항상 동작. Tab으로 사이드바·목록 포커스 전환.

맞춤 설정 & 멀티 윈도우

라이트/다크, 터미널 앱(iTerm/Terminal), 목록 크기 80~180%, 폴더 용량 계산 등. 창마다 독립된 탐색·히스토리.

AI 파일 정리

“말하면” 정리되는 폴더

어수선한 폴더에서 ✨ 버튼을 누르고, 하고 싶은 일을 한국어로 적으세요. AI가 파일 목록을 읽고 옮기기·삭제 계획을 만들어 보여줍니다. 확인을 누르기 전엔 아무것도 바뀌지 않습니다.

  • 두 가지 엔진 — 로컬 Ollama(기기 밖으로 데이터가 안 나감) 또는 Gemini. 클라우드 실패 시 로컬로 자동 폴백.
  • 안전 우선 — 삭제는 영구 삭제가 아니라 휴지통으로(복구 가능). 시스템·앱 폴더는 자동 제외, 예외 폴더도 직접 지정.
  • 제안된 모든 동작을 먼저 검토하고 적용.

파일 관리자 안에 들어온 활성 상태 보기

탐색하는 동안 툴바 한쪽에서 CPU·메모리·디스크가 2초마다 갱신됩니다. 숫자를 누르면 상세 팝오버가 열리죠.

  • CPU — 사용률 추이 그래프, SMC 센서 기반 온도(℃), 부하가 큰 프로세스 목록(바로 종료).
  • 메모리 — 앱·활성·와이어드·압축됨·스왑 분류와 메모리 압력, 사용량 상위 프로세스.
  • 디스크 — 용량을 종류별로 분류, 휴지통 비우기, S.M.A.R.T. 상태와 드라이브 온도.

한글 파일명 복원

“ㅎㅏㄴㄱㅡㄹ”처럼 깨진 이름, 한 번에

외장 디스크나 압축 파일을 거치며 한글이 자소 단위로 분리되면(NFD) 터미널·다른 OS에서 이름이 깨져 보입니다. XFinder는 이런 파일을 찾아 정상 완성형(NFC)으로 되돌립니다.

  • 툴바 ‘가나’ 버튼 클릭은 이 폴더만, 우클릭은 하위 폴더까지.
  • 바꾸기 전 대상 목록을 미리 보여주고 확인을 받습니다.
