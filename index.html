왜 만들었나

파인더는 좋지만, 늘 아쉬웠던 것들

매일 쓰는 파일 관리자라면 키보드만으로 막힘없이 움직이고, 어수선한 폴더는 한마디로 정리되고, 안 쓰는 앱은 찌꺼기까지 깔끔하게 지워지면 좋겠다고 생각했습니다.

XFinder는 Finder의 익숙한 레이아웃을 그대로 가져오되, 그 위에 평소 직접 손이 가던 작업들 — AI 정리, 시스템 모니터링, 앱 삭제, 한글·윈도우 파일명 정리 — 을 하나의 네이티브 앱으로 묶은 개인 프로젝트입니다.

필요한 건 다 들어있습니다

기본 탐색·파일 작업부터, 파인더에 없는 똑똑한 기능까지.

파인더 스타일 탐색

즐겨찾기·위치·태그 사이드바와 디스클로저 트리, 클릭 가능한 경로 막대, 뒤로/앞으로/상위 히스토리. 익숙한 그대로입니다.

완전한 파일 작업

새 폴더·이름 변경·복제·휴지통 이동, 그리고 복사 / 잘라내기 / 붙여넣기 클립보드. 파인더·다른 앱과도 클립보드를 주고받습니다.

AI 파일 정리★ 특별

“hwp 파일 휴지통으로, 이미지는 그림 폴더로” 한국어 한 줄이면 AI가 정리 계획을 세워 보여줍니다. 로컬 Ollama 또는 Gemini.

시스템 모니터★ 특별

툴바에 CPU·메모리·디스크 사용률이 실시간으로. 클릭하면 추이 그래프, CPU 온도, 메모리 분류, 디스크 용량·S.M.A.R.T. 상태까지.

앱 완전 삭제★ 특별

AppCleaner처럼 — 앱을 지울 때 캐시·환경설정·컨테이너 등 흩어진 관련 파일까지 찾아 한 번에 휴지통으로. 보호된 항목은 Finder에 위임.

한글 파일명 복원★ 특별

자소가 분리돼 “ㅎㅏㄴ”처럼 깨진 한글 이름(NFD)을 정상(NFC)으로 복원. 이 폴더만, 또는 하위 폴더까지 한 번에.

윈도우 호환 파일명

파일을 만들거나 이름을 바꿀 때 \ / : * ? " < > | 같은 금지 문자와 예약 이름을 자동 정리해 윈도우에서도 깨지지 않게.

파인더 태그

macOS 표준 7색 태그를 그대로 읽고 씁니다. 사이드바에서 색을 누르면 그 태그가 붙은 파일만 스포트라이트로 모아 보여줍니다.

최근 항목 & 빠른 검색

스포트라이트 기반 ‘최근 항목’(종류별 필터 지원), 그리고 현재 폴더의 모든 하위 폴더를 훑는 즉시 검색.

압축 & 미리 보기

ZIP 압축·압축 풀기를 진행 표시와 함께. Space / F3로 macOS 기본 Quick Look 미리 보기.

키보드 우선

전역 키 모니터로 목록을 클릭하지 않아도 25개 이상의 단축키가 항상 동작. Tab으로 사이드바·목록 포커스 전환.

맞춤 설정 & 멀티 윈도우

라이트/다크, 터미널 앱(iTerm/Terminal), 목록 크기 80~180%, 폴더 용량 계산 등. 창마다 독립된 탐색·히스토리.

AI 파일 정리

“말하면” 정리되는 폴더

어수선한 폴더에서 ✨ 버튼을 누르고, 하고 싶은 일을 한국어로 적으세요. AI가 파일 목록을 읽고 옮기기·삭제 계획을 만들어 보여줍니다. 확인을 누르기 전엔 아무것도 바뀌지 않습니다.

  • 두 가지 엔진 — 로컬 Ollama(기기 밖으로 데이터가 안 나감) 또는 Gemini. 클라우드 실패 시 로컬로 자동 폴백.
  • 안전 우선 — 삭제는 영구 삭제가 아니라 휴지통으로(복구 가능). 시스템·앱 폴더는 자동 제외, 예외 폴더도 직접 지정.
  • 제안된 모든 동작을 먼저 검토하고 적용.

탭으로 여러 폴더를, 그룹으로 한눈에

색깔 탭으로 폴더들을 오가고, 목록은 종류·크기·날짜 구간으로 묶어 봅니다.

다중 탭★ 신규

파인더처럼 한 창에서 여러 폴더를 탭으로 — ⌘T 새 탭, ⌘W 닫기, ⌃Tab 전환, 폴더 우클릭 ‘새 탭에서 열기’. 탭마다 폴더·선택·정렬·히스토리가 완전히 독립입니다.

색깔로 구분되는 탭★ 신규

탭을 만들 때마다 파스텔 색이 자동 배정됩니다 — 파랑·초록·주황·보라·분홍이 돌아가며 칠해져 어느 탭이 어느 폴더인지 한눈에. 탭을 닫아도 남은 탭의 색은 그대로 유지됩니다.

다음으로 그룹화

툴바의 그룹화 메뉴에서 이름·종류·크기·수정일·생성일 구간으로 목록을 묶어 봅니다. 스크롤해도 상단에 고정되는 그룹 헤더(제목+개수), 날짜는 오늘·어제·지난 7일·연도별로 — 파인더의 그룹 보기 그대로.

기본 탭 저장

설정 → 일반에서 ‘현재 열린 탭을 기본으로 저장’ — 자주 쓰는 폴더 조합을 저장해 두면 앱을 켤 때마다 그 탭들로 바로 시작합니다. 언제든 ‘지우기’로 기본 동작(최근 항목)으로 복귀.

매일 날짜를 확인하고, 일정을 잡고, 날씨까지 — 앱 전환 없이 메뉴 바 한 번만 클릭하면 전부 됩니다.

캘린더를 열 때마다 맥 전체 일정 앱이 뜨는 것이 번거롭다면, 달력·날씨·이벤트가 한 팝오버에 담긴 DayFlow를 써보세요.

새 버전 — v3.3

앱 Dock · 메뉴바 CPU · Citrix 한/영까지

실행 중인 앱을 화면 가장자리에 런처 바(⌥⌘D)로 상시 띄우고, 메뉴바에서 CPU 사용량 그래프를 실시간으로 봅니다. Citrix VDI의 원격 한/영도 오른쪽 옵션 없는 외장 키보드까지 확실하게 잡았습니다.

앱 Dock — 화면 가장자리 런처 바★ 신규

실행 중인 앱과 고정한 앱을 macOS Dock 같은 런처 바로 원하는 모니터의 가장자리(상·하·좌·우) 또는 드래그한 사용자 위치에 상시 띄웁니다. 전역 단축키(기본 ⌥⌘D)로 바로 열고 닫아요. 클릭으로 전환·실행하고, 자주 쓰는 앱은 핀으로 고정하세요.

메뉴바 CPU 그래프★ 신규

메뉴 바에 CPU 사용량 실시간 그래프를 띄웁니다 — 부하에 따라 색이 바뀌어 한눈에 상태를 읽을 수 있어요. RunCat처럼 요란한 애니메이션 없이, 조용하고 정확한 상시 모니터로 시스템 부하를 늘 곁에 둡니다.

Citrix 원격 한/영 — 외장 키보드까지★ 신규

Citrix 등에서 오른쪽 Alt가 AltGr(윈도우 키 눌림)로 오해석되던 문제를 우회하는 "오른쪽 ⌘" 전환 방식을 더했습니다. 오른쪽 옵션 키가 없는 외장 키보드(예: Crush 80)에서는 오른쪽 ⌘→⌥ 를 HID 레벨로 바꿔, 물리 키처럼 부작용 없이 한/영을 토글합니다.

화면 보호기 단축키 — ⌘L 한 번★ v3.2

위젯의 플립 시계를 단축키 하나로 화면 보호기로 즉시 실행합니다(기본 ⌘L). 어느 앱에서든 바로 켜지고, 위젯 설정에서 원하는 조합으로 자유롭게 지정할 수 있습니다. 단축키를 녹화하는 동안에는 가로채기를 잠시 멈춰 겹치는 조합도 그대로 지정됩니다(스크린샷 단축키 칸에도 동일 적용).

VDI · 원격 데스크톱 단축키 통과★ v3.1

Citrix·RDP·Parallels 등 가상화(Windows) 창에서 맥이 가로채던 단축키를 끄고 키를 원격으로 그대로 흘려보냅니다. 미션 컨트롤·Spotlight·⌃Space·⌘Tab, 볼륨·F10 같은 미디어/F 키까지 맥이 먼저 삼키던 조합을 그 앱에서 가로채 원격으로 직접 전달합니다. 단축키 탭에 앱(Citrix Viewer·Windows App 등)을 추가하면 끝.

키보드를 통째로 — 미디어·F키까지★ v3.1

왼쪽 ⌘ ↔ ⌥ 를 실제 키보드(HID) 레벨에서 맞바꿔 단일 키든 조합이든 일관되게 동작합니다. 볼륨·밝기·F10 같은 미디어/F 키도 가로채 원격에 F1~F12 로 — ⇧F10 이 Windows 컨텍스트 메뉴로 그대로 전달됩니다. 명시적 한/영 규칙은 통과보다 우선하는 예외로 유지합니다.

화면 캡처 — 대상 창이 닫히지 않아요★ v3.1

영역·창 캡처 오버레이가 더 이상 대상 앱의 포커스를 빼앗지 않습니다(non-activating 패널). 포커스를 잃으면 닫히던 패널·팝오버도 사라지지 않고 그대로 담깁니다. 단축키 직후 바로 드래그·클릭도 그대로.

잠자기 표시 · 더 깔끔한 설정★ v3.1

잠자기 방지를 켜면 아이콘이 파란색으로 바뀌고 남은 시간(또는 "무제한")을 함께 보여줍니다. 일반 설정 탭은 항목·섹션 간격을 줄여 세로 스크롤 없이 한 화면에 깔끔하게 정리했습니다.

영역 · 창 · 전체화면 캡처★ v3.0

단축키 하나로 즉시 시작합니다 — ⌃⇧A 영역, ⌃⇧F 전체화면, ⌃⇧W 창. 영역 선택은 화면을 어둡게 딤 처리하고 크로스헤어와 실시간 픽셀 치수를 보여주며, 단축키를 누른 즉시 드래그됩니다(첫 클릭이 버려지지 않음). 창 캡처는 마우스 아래 창을 자동 하이라이트해 카메라 커서로 클릭 한 번에. 다중 모니터·레티나 네이티브 해상도 그대로 담깁니다.

스크롤 캡처 — 긴 페이지를 한 장으로★ v3.0

⌃⇧S로 영역을 정하고 그 안에서 스크롤만 하면, 지나간 화면을 자동 겹침 검출로 세로로 이어붙여 화면 밖 내용까지 하나의 긴 이미지로 만듭니다. 이어붙는 모습은 옆 패널에서 실시간 미리보기로 확인하고 원하는 길이에서 완료하면 끝 — 웹페이지·긴 대화·코드 전체를 통째로 담을 때 좋습니다.

마크업 에디터 — 도구 10종★ v3.0

캡처 직후 바로 주석을 답니다 — 화살표·선·사각형·타원·자유선·형광펜·텍스트·번호 카운터, 그리고 민감한 정보를 가리는 흐리기·픽셀화. 그린 객체는 나중에도 선택·이동·크기 조절이 되고 Undo/Redo를 지원합니다. 색·굵기를 고르고 필요한 부분만 크롭한 뒤 PNG·JPG·HEIC(@2x)로 내보내거나 바로 복사하세요.

OCR — 화면 속 글자를 텍스트로★ v3.0

⌃⇧T로 영역을 캡처하면 그 안의 글자(한국어+영어+숫자)를 고정밀 인식해 클립보드에 바로 넣습니다. 복사가 막힌 화면, 이미지 속 글자, 스캔된 PDF의 텍스트도 그대로 가져와 붙여넣을 수 있습니다. Quick Access 썸네일에서도 한 번에 OCR이 됩니다.

Quick Access · 화면 고정(Pin)★ v3.0

캡처하면 화면 구석에 썸네일이 떠(최대 6장까지 쌓임) 복사·저장·마크업·OCR·핀·드래그아웃을 그 자리에서 처리합니다. 핀(Pin)은 캡처를 모든 창 위에 띄워두는 기능으로(투명도 조절), 참고 화면을 옆에 두고 작업할 때 유용합니다.

캡처 후 동작 자동화 · 저장 옵션★ v3.0

캡처 한 번에 클립보드 복사 + 파일 저장 + 에디터 열기 + 오버레이를 동시에(원하는 것만 켜기). 파일명 템플릿(날짜·시간 변수)·PNG/JPG/HEIC 포맷·셀프 타이머·셔터음·플래시·이전 영역 재캡처까지 세밀하게 조절합니다. 클립보드는 PNG+TIFF로 복사돼 메신저·웹 입력창 어디에 붙여넣어도 깨지지 않습니다.

한/영 전환 — 카라비너 없이, 원격 Windows까지★ v3.0

원하는 키 하나(예: ⌃Space, 오른쪽 ⌘)로 한/영을 바꿉니다. Mac은 입력 소스를 직접 전환해 확실하게, Citrix·RDP 등 원격 Windows는 오른쪽 Alt 신호로, 그리고 둘을 동시에 같은 언어로 맞추는 모드까지 골라 쓰세요. Karabiner 설치나 복잡한 JSON 없이 설정 창에서 클릭 몇 번 — 적용 앱을 Citrix Viewer로 한정하면 원격 안에서만 동작합니다.

키보드 단축키 리맵핑★ v2.2

연결된 키보드별(내장·외장·특정 기기)로, 특정 앱 또는 모든 앱에서 키 조합을 다른 키로 바꿉니다. 모디파이어 토글+드롭다운, 또는 직접 누르기로 지정 — macOS 전용 Karabiner 같은 동작.

키보드별 · 앱별 정밀 매핑★ v2.2

내장·외장·특정 기기 등 입력이 들어온 키보드를 구분하고, 특정 앱 또는 모든 앱에서만 규칙을 적용합니다. 모디파이어 토글+드롭다운으로 고르거나 직접 누르기로 그대로 녹화 — 두 방식 모두 지원.

더 단순해진 설정★ v2.2.1

메뉴 바 톱니바퀴를 누르면 설정 창이 바로 열립니다. 종료는 설정 창의 "DayFlow 종료" 버튼으로 깔끔하게 정리했습니다.

플립 시계 스크린 세이버★ v2.1

MacFlip 스크린 세이버가 DayFlow에 내장됐습니다. 설정에서 원클릭 설치 후 시스템 설정 → 화면 보호기에서 "DayFlow"를 선택하면 끝 — 자리를 비우면 화면 전체가 플립 시계가 됩니다.

바탕화면 플립 시계 위젯★ v2.0

배경화면 바로 위·모든 창 아래에 고정되는 플립 시계가 시각·날짜·현재 기온을 보여줍니다. 클릭은 그대로 바탕화면으로 통과하고, 표시할 모니터도 고를 수 있습니다.

크기 5단계 · 위치 프리셋★ v2.0

소·중·대에 특대·최대가 더해진 5단계 크기. 위치도 가운데를 포함한 5개 프리셋에서 고르거나, 편집 모드에서 드래그해 원하는 자리에 자유롭게 둡니다.

배경 투명 모드★ v2.0

검은 패널은 물론 플립 타일 배경까지 투명하게 — 숫자는 얇은 테두리 선으로만 구분되어, 배경화면 위에 시계만 떠 있는 듯한 모습이 됩니다.

말풍선 달력 팝오버★ v2.0

달력이 화면 구석이 아니라 메뉴 바 아이콘 바로 아래, 아이콘을 가리키는 화살표가 달린 말풍선으로 열립니다. 위치는 고정되어 항상 같은 자리에 뜹니다.

기능 둘러보기

작고 가볍게, 그러나 꽉 찬 기능

메뉴 바 하나에서 달력, 날씨, 이벤트 편집까지.

메뉴 바 캘린더

앱 전환 없이 메뉴 바 클릭 한 번으로 이번 달 달력을 바로 열어봅니다. 떠있는 팝오버 스타일이라 다른 앱 위에도 겹쳐 표시됩니다.

한국 공휴일 자동 인식

macOS 캘린더의 "대한민국 공휴일" 달력을 자동으로 감지합니다. 토·일요일과 공휴일은 빨간색으로 강조됩니다.

이벤트 편집 ✦ EventKit

macOS 캘린더 앱과 완전 연동. 날짜를 클릭하면 당일 일정을 보고, 새 이벤트를 생성·수정·삭제할 수 있습니다. 반복/알람도 지원.

날씨 위젯

GPS 또는 IP 기반 자동 위치 감지. Open-Meteo 무료 API로 현재 날씨와 최고·최저 기온을 팝오버 하단에 표시합니다. 수동 도시 선택도 가능.

바탕화면 플립 시계 위젯 ★ v2.0

배경화면 바로 위에 고정되는 플립 시계가 시각·날짜·현재 기온을 보여줍니다. 크기 5단계, 위치 프리셋, 배경 투명 모드까지.

플립 시계 스크린 세이버 ★ v2.1

같은 디자인의 플립 시계를 화면 보호기로도. 설정에서 원클릭 설치하고 시스템 설정 → 화면 보호기에서 "DayFlow"를 선택하세요.

잠자기 방지

커피 잔 버튼 하나로 맥이 잠자기 상태로 진입하는 것을 차단합니다. 30분 · 1시간 · 2시간 프리셋 또는 무제한 선택 가능.

핀 고정 모드

캘린더 팝오버를 핀으로 고정하면 다른 곳을 클릭해도 닫히지 않습니다. 일정을 보면서 다른 작업을 할 때 유용합니다.
